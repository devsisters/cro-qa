## 결과 읽는 법

| 표기 | 뜻 |
|---|---|
| 통과 (PASS) | 기대 조건과 정답지 비교를 통과했다(자동 판정) |
| 실패 (FAIL) | 기대와 다르다 — 결함 의심. 근거와 캡처를 본다 |
| 확인 필요 (REVIEW·UNSURE) | 정답지와 차이가 있는데 자동 판정이 확신하지 못했다 — 사람이 본다 |
| 진행 실패 (ERROR) | 화면 이동·연결이 안 됐다 — 결함일 수도, 케이스가 낡았을 수도 있다 |
| 미실행 (NOT_RUN) | 돌리지 않았다(소리·결제·계정 상태 필요 등, 이유 표기) |
