# QA 자동화 테스트 키트

기능 테스트 시트를 주면 Claude 가 iPad·Android 실기기에서 게임을 조작해 케이스를 돌리고, 정답지와 비교해 판정하고, 리포트를 만든다.

1. **시트 링크 공유** → 케이스 파일로 변환(자동화 못 하는 케이스는 이유와 함께 분리)
2. **iOS·Android 자동 실행** → 게임 DEBUG 빌드의 자동화 연결(AgentBridge)로 화면을 이름으로 읽고 누른다
3. **정답지와 비교·판정** → 화면 구조(트리) 조건 → 승인된 정답 화면 비교 → 차이만 낮은 모델이 분류
4. **리포트** → report.md, 시트에 붙여 넣을 results.tsv/csv

시작: `SETUP.md`(설치) → 이 폴더에서 `claude` → `PROMPTS.md` 1번.
화면으로 쓰려면 **QA 앱**(`app/`): 케이스·수치를 폼에서 고치고 「테스트 시작」 → 진행 로그 → 리포트(판마다 조합·되감기 시각·캡처) → Claude 진단·대화. 설치는 저장소 맨 위 `README.md`, 사용법은 `app/README.md`.
인게임 자동 되감기(부활·보너스 복귀·N초마다)는 `CLAUDE.md` 3-2.
Claude 작업 지침은 `CLAUDE.md`, 케이스 형식은 `cases/README.md`, 정답지는 `answers/README.md`.

## 알아 둘 것

- 게임은 **DEBUG 빌드**여야 한다(CI Cookiepot debug 단계)
- 정답지는 **사람이 승인한 화면**이다. 첫 실행은 시트 기대 조건으로만 판정되고, 승인한 뒤부터 화면 비교가 붙는다
- 「통과」는 자동 판정이다. 소리·손맛·연출 품질은 사람이 본다(미실행으로 표시된다)
- 결제·계정 연동·로그아웃·선택 동의는 누르지 않는다. 재화를 쓰는 케이스는 허락할 때만 돈다
